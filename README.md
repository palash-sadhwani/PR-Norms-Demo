# PR-Norms-Demo

A deliberately small inventory service used to demonstrate
[PR-Norms](https://github.com/palash-sadhwani/PR-Norms).

**Demonstration content.** The pull requests and review discussions in this
repository are scripted scenarios, written with Claude Code and posted from the
repository owner's account. They show recurring review feedback (hardcoded
credentials, missing input validation, swallowed exceptions, queries in loops,
missing regression tests, sensitive data in logs) so PR-Norms can mine those
norms and apply them to the open pull request.

Run the tests with `python -m pytest`.
